## How I engineer

- Start with clear service boundaries and explicit API contracts.
- Design failure handling, security, and observability with the feature—not afterward.
- Use tests and automation to make delivery repeatable.
- Trace production problems across UI, API, messaging, database, and cloud layers.
- Document trade-offs so the next engineer can operate the system confidently.
